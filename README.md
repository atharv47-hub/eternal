# AK47 — Classified Ethical Hacker Bio Page

Mobile-first Instagram bio website for GitHub Pages.

## Included
- `index.html`, `style.css`, `script.js`
- `assets/atharv-profile.jpeg` — supplied profile photo
- `assets/montagem-diamante-rosa.m4a` and `assets/baila-lento.mp3` — supplied tracks

## Audio autoplay note
The site attempts to start the first track automatically and loops it. Modern browsers (especially mobile Safari/Chrome) often block **audible autoplay** until the visitor taps the page or presses Play. If blocked, use the on-page Play button. Track selector lets visitors choose either supplied song; both loop.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload **all files and the `assets` folder** into the repository root. Do not upload only the HTML file.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for deployment and open the generated URL.
